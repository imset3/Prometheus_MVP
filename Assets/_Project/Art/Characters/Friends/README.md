# Meeting-room friend sprites

Place each finished transparent PNG in the matching character folder.

Expected filenames:

- `Eon/Eon_Meeting.png`
- `Aron/Aron_Meeting.png`
- `Elium/Elium_Meeting.png`

Recommended source format:

- transparent PNG
- one full-body standing or seated-neutral pose
- character centered with padding around the silhouette
- no background, floor, shadow, text, or UI
- keep the original canvas size and pixels-per-unit consistent between all three characters

The Unity scene placement targets are the existing `A-MEETING-SEAT-*` markers. Player Prome and guide Theus use their existing runtime objects and are not duplicated in this folder.
