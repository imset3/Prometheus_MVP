# Tutorial C corridor props

Generated with the built-in OpenAI image generation tool on 2026-08-02.

References: Prome_Idle.gif for handmade linework, TUTO_AC_Platform_Middle_v1.png
for the warm walnut/brass palette, and Expansion_C_Corridor_Gameplay.png for
scale and placement context.

All four assets use the same production direction: readable hand-painted anime
game props for an old but operational airborne-headquarters service corridor,
with dark outlines, simplified forms, gentle cel shading, tarnished metal,
scratches, dents and repairs. Sources were generated on a flat #00FF00
chroma-key background and locally converted to alpha PNGs.

- Transport crates: two reinforced walnut cargo crates plus a canvas dispatch satchel.
- Maintenance chest: low open parts trunk with cable and oversized tools.
- Overhead pipes: two copper/brass utility lines with valve, gauge, patched coupling and ether conduit.
- Structural column: full-height load-bearing support with brass bands and a restrained ether indicator.

Source files are in Source; transparent Unity assets are in Generated.
