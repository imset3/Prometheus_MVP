# 튜토리얼 기능 마커 배치 가이드

튜토리얼 레벨은 코드 좌표가 아니라 씬의 기능 마커를 기준으로 동작한다. 레벨 수정 시 마커를 이동·회전·스케일하고, 마커 아래의 기능 오브젝트는 자식 관계를 유지한다.

## 공통 원칙

- `*_MARKER`, 스폰, 목표, 체크포인트 Transform이 기능 위치의 단일 기준이다.
- 마커를 옮길 때 자식 오브젝트를 따로 옮기지 않는다.
- 바람 마커는 위치가 적용 범위, 회전의 위쪽 축(`transform.up`)이 바람 방향이다.
- 바람 범위는 자식 `BoxCollider2D` 크기로 조절한다.
- 적 생성 위치, 구역 이동 도착점, 재시작 위치, 목표 화살표 위치는 대응 마커 Transform을 직접 참조한다.
- 추천 위치 적용 메뉴는 초기 배치 또는 의도적인 초기화에만 사용한다. 팀원이 마커를 수동 배치한 뒤에는 다시 실행하지 않는다.

## 훈련장

단계 순서는 `대시 → 더블점프 → 점프 → 근접 → 원거리`다.

- `01_대시`부터 `05_원거리공격`까지 단계 루트 중 현재 단계 하나만 활성화된다.
- 모든 단계는 같은 훈련장 공간을 재사용한다.
- 각 단계 시작/실패 복귀는 `훈련_진입` 마커를 사용한다.
- 대시 단계의 빨간 장치 3개는 대시 중에만 안전하게 통과할 수 있다.
- 대시 도착 마커에 닿으면 불기둥이 꺼지고 다음 단계가 활성화된다.
- 단계 밖에서 미리 수행한 행동은 카운트하지 않는다.

## 숨겨진 방

- `HiddenRoomSpawn`: 낮은 진입 위치
- `LedgeStop`: 활공 안내 시작 위치
- `PasskeyTarget`: 높은 패스키 위치
- `HiddenReturnTarget`: 낮은 출구 위치. 도달 후 `F`로 나간다.
- `HiddenRoom_Updraft_MARKER`: 이동으로 범위 변경, 회전으로 상승 방향 변경

입구·절벽·패스키·출구 판정 콜라이더는 각각의 마커 자식이므로 마커만 옮기면 판정도 함께 이동한다.

## F/G 전투 구역

- 적은 `EnemySpawn` 마커에서 생성된다.
- 적을 모두 처치하기 전에는 출구가 잠긴다.
- F/G 바람은 파란 도형을 기준으로 생성된 바람 마커가 담당한다.
- G는 두 그룹의 적을 순서대로 활성화하며 중간 통로 도달 마커가 다음 그룹을 연다.
- 사망 시 해당 구역 체크포인트 마커로 복귀한다.

## 선착장·헬테

- G 출구 전환은 선착장 루트와 `H_Helte_Integration`을 함께 활성화한다.
- 헬테 조우 대화, 재시작 체크포인트, 보스 진입 목표는 선착장 기능 루트의 Transform 참조를 사용한다.
- 선착장 레벨을 옮길 때 기능 루트와 마커를 같은 최고 부모 아래에서 함께 이동한다.

## 수정 후 검증

Unity 메뉴에서 다음 순서로 확인한다.

1. `sragon000 > Validation > Validate Active Tutorial Scene`
2. `sragon000 > 튜토리얼 > 가져온 훈련장 플레이 테스트 실행`
3. `sragon000 > 튜토리얼 > 가져온 전체 튜토리얼 플레이 테스트 실행`
