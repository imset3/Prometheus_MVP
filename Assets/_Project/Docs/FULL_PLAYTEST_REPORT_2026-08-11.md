## 실제 전체 흐름 검증 범위

`TrainingThroughHelte_CompletesTheTutorialThroughLiveSceneSystems`가 다음 진행을 실제 런타임 시스템으로 순서대로 통과했다.

1. 회의장·숨겨진 방·패스키·복귀 흐름
2. 대시 → 더블 점프 → 점프 → 근접 → 원거리 훈련
3. 외부 F·G 전투와 H 선착장 진입
4. 원거리 공격(1), 테우스 집중포화(2), 프로메 4연속 참격(3) 순차 해금과 표시
5. 헬테 조우·전투 시작·처치
6. 선착장 자동 이동, 비행정 탑승, H 월드 숨김, 제니스 항해, 데모 종료
7. 헬테 처치 후 보스 체력바와 1·2·3번 스킬 아이콘을 포함한 전체 플레이 HUD 숨김

## 2026-08-11 최종 QA 재실행

- Unity 공식 MCP에서 검색된 전체 테스트는 126개(EditMode 115, PlayMode 11)이며 전부 통과했다.
- `TutorialScene`은 저장 완료·비재생 상태였고 검사 전후 콘솔 오류는 0건이었다.
- 빌드 설정에는 `TitleScene`, `Boot`, `TutorialScene`, `BossDevelopmentScene`, `Chapter01`이 모두 활성 상태로 등록되어 있다.
- Scene Doctor의 54건은 기존 레벨 설계용 비가시 충돌체 경고이며 오류 항목은 없다. G→H 통행 회귀는 전용 PlayMode 테스트로 별도 통과했다.
- 실제 Unity Game 뷰에서 타이틀 배경·제니스·프로메·`PROME&THEUS` 로고, 입력 후 5개 메뉴, 튜토리얼 대화창과 `SPACE` 안내, `ESC` 일시정지 메뉴를 육안 확인했다.
- 보스 개발 씬은 메인 배경·제니스·프로메/테우스·스킬 HUD가 표시되고 런타임 오류 없이 시작됐다.
- 최근 수정한 F/G 원거리 적 투사체는 전용 EditMode 구성 검사와 PlayMode 가시성 검사를 모두 통과했다.
- 더블점프 발판 3개의 Collider 상단을 장식 링 최고점이 아닌 실제 발판 상판 높이로 맞추고, 최고점 도착 마커도 같은 기준으로 이동했다.
- 유도 화살표는 10개 퀘스트 목표 전체에서 원거리 표시, 2축 방향 회전, 도착 시 숨김을 검증했다.
- 기본 해상도는 1920×1080이며 드롭다운은 실행 디스플레이가 지원하는 1280×720 이상 모드를 중복 제거해 표시한다.
- 헬테 모션 전체 재제작이 필요하다는 아트 QA 판정에 따라 신규 빌드, GitHub Release 및 main 푸시는 보류했다.

## 2026-08-11 최종 결함 수정 재검증

- 원거리 훈련은 중앙에 배치된 기존 `Enemy` 더미 3개를 실제 피격 대상으로 사용한다.
- 별도 `RangedTarget_01~03` 스폰 오브젝트는 씬에서 제거했다.
- 나디르 선착장 전환은 도착 지점 위 0.12m 여유와 2회 FixedUpdate 정착을 적용해 접촉 반동과 바닥 끼임을 방지했다.
- 헬테는 원본 프레임의 좌향 구성을 반영해 블링크·돌진·공격 상태 변경 즉시 플레이어를 바라본다.
- 프로메 3번 검기는 오른쪽 원본 이미지를 기준으로 왼쪽을 볼 때만 반전된다.
- 헬테 처치 직후 모든 플레이 HUD를 숨기되, 데모 시네마틱·결과 오버레이는 유지한다.
- 타이틀 화면 복귀 버튼은 하단 중앙 560×116으로 확대했다.
- 헬테 처치 전용 16초 프로토타입 BGM을 생성하고 승리 구간 재생 슬롯에 연결했다.
- 집중 테스트: 원거리 훈련 1/1 통과(7.09초), 전체 튜토리얼 1/1 통과(35.18초).

### G→H 진입부 추가 교정

- 현장 재현 위치 `(630.4, -3.5)`에서 좌·상·우 충돌 프록시가 플레이어와 동일한 높이의 U자 통로를 만들어 진행 중 튕김과 바닥 끼임을 발생시켰다.
- `G-H-ENTRY-TILEMAP-CLEARANCE` 영역으로 레거시 프록시 3개와 재구성 타일 셀을 함께 제외했다.
- 이후 플랫폼 재구성도 이 마커를 존중하므로, 오브젝트가 배치된 공간에 타일맵이 다시 덮이는 회귀를 막는다.
- Scene Doctor 오류 0, 사전·사후 스냅샷 비교 완료.
- Unity 편집기를 재시작해 정지했던 Test Runner 세션을 정리한 뒤 자동 G→H PlayMode 테스트 `1/1` 통과(24.83초).
- 테스트는 G 전투 완료 이후 Rigidbody 플레이어를 실제로 우측 이동시켜 통행 여유 마커의 오른쪽 끝을 넘는지 확인한다.

## 테스트 중 발견·수정한 결함

첫 실행은 헬테 처치 후 1번 원거리 공격 아이콘이 남아 실패했다. 원인은 보스 오브젝트가 초기 비활성 상태일 때 `RangedAttackCooldownPresenter`와 `TheusFocusedVolleyPresenter`가 `TutorialBossArenaHost` 참조를 찾지 못한 것이었다.

- 비활성 오브젝트를 포함해 보스 아레나를 탐색하도록 수정
- 런타임에도 참조가 없으면 재탐색하도록 보강
- 같은 전체 테스트 재실행 후 통과

## 프로메 신규 아트 검증

- Dash: 30프레임, 120fps, 비루프 클립으로 생성
- Jump: 30프레임, 30fps, 비루프 클립으로 생성
- 낙하 전용 클립이 없을 때 Jump 마지막 자세를 유지해 공중에서 Idle/Run으로 돌아가지 않음
- 기존 캐릭터 부모의 Rigidbody2D·Collider2D·게임플레이 판정은 변경하지 않음
- 표정 7종은 프로메 대화 초상화에 연결
  - 기본·정색·한숨 문맥 선택
  - 말하는 동안 닫힌 입/열린 입을 반복
- PNG 폴더 도구가 `Face` 폴더를 번호 시퀀스 오류로 처리하지 않도록 제외
