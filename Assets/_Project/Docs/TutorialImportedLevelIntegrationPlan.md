# 튜토리얼 신규 레벨 통합 개발계획서

## 1. 문서 목적

팀원이 제작한 신규 레벨 구역 도형은 수정하지 않고 `TutorialScene`의 기준 배치로 보존한다.
기존 `TutorialScene`에 구현된 튜토리얼 시스템을 별도의 연동 계층으로 이식하여,
최신 노션 시나리오와 사용자가 확정한 규칙에 맞는 1회 완주 가능한 챕터 0을 구성한다.

이 문서의 `확정` 항목만 구현한다.
`미결정` 항목은 사용자 확인 전 임의로 구현하지 않는다.
노션의 `(수정중)` 및 `[제안]` 표시는 사용자 확인 없이 적용하지 않는다.
사용자의 직접 지시가 노션과 충돌하면 사용자의 직접 지시를 우선한다.

### 용어: 판도라

- `판도라 시스템`은 제니스와 데미우르고스 측이 운용하는 자동화·통제·전투 체계다.
- `판도라 개체` 또는 `판도라 유닛`은 판도라 시스템에 속한 로봇 전력이다.
- 챕터 0에서 본부를 습격하고 F/G에서 상대하는 적은 판도라 유닛이다.
- 엔딩의 판도라 불빛은 특정 인물이나 단일 보스가 아니라,
  아직 본부와 프로메 일행을 추격 중인 판도라 부대의 접근을 뜻한다.

## 4. 신규 레벨 도형 보존 원칙

- 팀원이 만든 구역 루트의 자식 오브젝트, 로컬 위치, 크기, 회전을 직접 수정하지 않는다.
- 기존 `훈련장`은 비활성 상태로 유지하고 `훈련장 수정버전`을 사용한다.
- 연동 오브젝트는 별도 `GameplayIntegrationRoot` 아래에 만든다.
- 연동 계층은 구역별 하위 루트로 구분한다.
  - `A_Meeting_Integration`
  - `B_HiddenRoom_Integration`
  - `C_Corridor_Integration`
  - `D_Training_Integration`
  - `E_Exterior_Integration`
  - `F_Encounter01_Integration`
  - `G_Encounter02_Integration`
  - `H_Helte_Integration`
- 도형 교체와 아트 연결은 연동 로직 완료 후 수작업으로 진행한다.

## 5. 구역 전환 공통 규칙

### 확정

- 하나의 Unity 씬 안에서 구역 위치를 이동한다.
- 일반 구역 전환은 페이드 인·아웃으로 처리한다.
- 플레이어가 출구에 도달하기 전에 카메라 추적을 구역 바운드에서 멈춘다.
- 플레이어 머리 위 방향 화살표는 목적지가 멀면 표시하고 목적지에 도착하면 숨긴다.
- 대화 진행 키는 Space로 통일한다.
- 플레이어 이동이 빨라도 필수 대화와 자막이 생략되지 않게 진행 게이트를 사용한다.

### 숨겨진 방의 테우스 조명

- 테우스가 별도의 손전등을 사용하는 연출이 아니다.
- 테우스 본체가 빛 형태로 변하고 패스키 방향으로 빛을 뻗는다.
- 빛 형태는 코어, 후광, 패스키 지향 빔의 세 아트 슬롯으로 구성한다.
- 패스키 획득 즉시 빛 형태를 해제하고 평상시 외형으로 복귀한다.
- 최종 스프라이트·이펙트는 `TheusLightFormRoot`의 아트 슬롯만 교체해 연결한다.

### 훈련장 습격 예외 전환

- `D → C_02`는 최신 노션대로 일반 페이드를 사용하지 않는다.
- 화면을 어둡게 전환한 상태에서 프로메가 뛰어가는 발소리를 재생한다.
- 발소리 연출이 끝나면 플레이어를 복도 시작점으로 순간이동시키고 화면을 복구한다.
- 이 연출 중에는 플레이어 입력과 대화 넘기기를 잠근다.

## 6. C 구역: 재사용 복도 설계안

### 권장 블록아웃

- 길이 약 30~40 유닛의 일자형 복도.
- 점프맵이나 전투 구간을 넣지 않는다.
- 양 끝에 회의장·훈련장/외부 방향 전환 앵커를 둔다.
- 중앙에 짧은 시야 환기 공간 또는 창고 흔적을 둬 화면이 지나치게 단조롭지 않게 한다.
- 같은 도형을 세 번 재사용하고 방문 상태에 따라 연출만 변경한다.

### 방문별 상태

- `C_01`: 정상 조명, 테우스의 짧은 세계관 설명, 훈련장 방향 유도.
- `C_02`: 붉은 경보, 먼지와 진동, 회의장 방향으로 되돌아가는 긴급 이동.
- `C_03`: 더 강한 진동과 잔해, 외부 방향으로 일방 이동.

### 확정된 제작 방향

- Codex가 위 권장 블록아웃을 우선 제작하고 사용자가 플레이 후 수정 의견을 전달한다.
- `C_01`은 회의장에서 훈련장 방향으로 진행한다.
- `C_02`는 같은 복도를 반대 방향으로 되돌아가 회의장으로 진행한다.
- `C_03`은 다시 외부 출구 방향으로 진행한다.
- 기존 사다리 이동 연출은 C_03의 외부 출구 앞 짧은 전환 구간으로 유지한다.
- 사다리 범위에 들어오는 것만으로는 작동하지 않으며, 안내가 표시된 상태에서 `F`를 눌러야 내려간다.
- 사다리 이동은 정밀 플랫폼 구간이 아니라 짧은 자동 하강 연출로 처리한다.

### 구현 결과

- C_03 상태 루트는 A_03에서 복도로 재출발할 때만 활성화한다.
- 직선 복도 이동 중 테우스 긴급 자막과 약한 진동을 각각 두 번 재생한다.
- 사다리 근처에서 `F: 사다리 내려가기` 안내를 표시한다.
- 플레이어가 `F`를 누른 뒤에만 입력과 물리를 잠시 멈추고 아래쪽 출구까지 자동 이동한다.
- 사다리 이동이 끝난 뒤 페이드하여 E 외부 시작점으로 전환한다.
- C_01·C_02의 기존 복도 이동에는 사다리와 C_03 연출이 섞이지 않는다.

## 7. E 구역: 본부 외부 설계안

### 권장 블록아웃

- 길이 약 30~45 유닛의 짧은 외부 전망 구간.
- 본부 출구, 습격 상황을 보여주는 전망 지점, F 진입 지점의 세 부분으로 구성한다.
- 적은 배치하지 않는다. 첫 실제 교전은 F에서 시작한다.
- 플랫폼 난도를 넣지 않고 긴박한 이동과 세계관 전달에 집중한다.
- 전망 지점에서 카메라가 잠깐 멈추고 판도라 습격 연출과 대사를 보여준다.

### 확정된 제작 방향

- Codex가 위 권장 블록아웃을 우선 제작하고 사용자가 플레이 후 수정 의견을 전달한다.
- 플레이어는 계속 이동할 수 있고 테우스의 설명은 자막으로 재생한다.
- 습격 전망 지점에서는 카메라만 잠시 멈추고 플레이어 조작은 유지한다.
- 현재는 아트를 연결하지 않고 순수 도형과 연출 앵커만 배치한다.
- 외부 배경 방향과 최종 아트는 수작업 아트 연결 단계에서 확정한다.

### 구현 결과

- 외부 원본 자식 도형은 수정하지 않고 기술 연동 계층에 흰 도형 충돌 프록시만 생성했다.
- 입장 시 외부 시작점과 카메라 바운드, 방향 안내, 사망 체크포인트를 갱신한다.
- 습격 전망 지점에서는 플레이어 조작을 막지 않고 카메라만 잠깐 고정한다.
- 카메라 고정과 함께 약한 진동 및 테우스 자막 2개를 재생한 뒤 추적을 복구한다.
- E 끝의 전환 지점에 도달하면 페이드 후 F 시작점으로 이동한다.
- E→F 전환 완료 시 `QST-TUTO-007-A`를 시작하고 F 시작점을 사망 체크포인트로 등록한다.
- 방향 안내는 F 출구를 가리키며, 전투를 완료하고 출구에 가까워지면 사라진다.

## 8. D 구역: 훈련장 진행

### 확정된 훈련 순서

1. 대시: 낙하물 3회 회피
2. 점프: 전방 투사체 3회 회피
3. 더블점프: 공중 2단 점프 1회 성공
4. 기본 공격: 훈련 적 1기에 3콤보 성공
5. 원거리 공격
6. 습격 발생

### 구현 공통 규칙

- 각 훈련은 해당 훈련 구역 안에서 수행한 행동만 카운트한다.
- 현재 훈련 이외의 도형·적·위험물은 비활성화한다.
- 실패하면 해당 훈련 시작점에서 다시 시작한다.
- 훈련이 완료되기 전 다음 단계 구역을 활성화하지 않는다.
- 훈련 대화와 안내 UI가 종료되기 전 성공 판정을 시작하지 않는다.

### 확정된 부츠와 원거리 기능

- 최신 노션의 안 A를 채택한다.
- 크리온은 이 흐름에 등장하지 않는다.
- 더블점프 부츠는 훈련장 진입 전에 이미 장비된 상태로 둔다.
- 테우스가 3단계 시작 시 부츠의 더블점프 사용법을 설명한다.
- 기존 펄스 모듈은 삭제 대상이다.
- 원거리 훈련에는 펄스 모듈이 아닌 플레이어의 기본 원거리 공격을 사용한다.
- 펄스 모듈 전용 퀘스트, 쿨다운 UI, 사용 안내는 신규 흐름에서 제거한다.
- 펄스 모듈 전용 퀘스트는 제거하고 같은 순서에 기본 원거리 공격 훈련을 연결한다.
- 모듈 시스템, 모듈 트리와 인벤토리 기반은 삭제하지 않고 유지한다.
- 기본 원거리 공격은 일반 평타가 아니라 쿨다운이 있는 스킬로 취급한다.
- 키보드 숫자 2를 눌러 원거리 공격을 발사한다.
- 발사 방향은 마우스 포인터의 월드 X 위치를 기준으로 플레이어가 바라보는 좌·우 방향을 사용한다.
- 원거리 공격 쿨다운은 1.5초로 설정한다.
- 일렬로 배치된 훈련 적 3기를 한 발로 동시에 관통 타격해야 훈련을 통과한다.

현재 프로젝트의 `PlayerRangedAttackHost`를 확장하여 사용한다.
기존 사거리 10유닛과 다중 관통 판정은 유지하고 쿨다운만 1.5초로 변경한다.
기존 숫자 2의 `Next/ModuleRequested` 연결은 원거리 공격 전용 입력으로 교체한다.
모듈 시스템은 보존하되 튜토리얼 도중 사용할 별도 모듈이 생길 때까지 실행 입력을 요구하지 않는다.

## 9. F/G 전투 스테이지

### 확정

- 적은 레벨에 직접 배치한다.
- 적 종류와 수는 이후 확정한다.
- 구역 진입 후 배치된 적을 모두 처치해야 출구가 열린다.
- 적이 남아 있으면 출구를 잠그고 다음 구역으로 진행할 수 없다.
- F/G 사망 시 현재 구역 시작점에서 다시 시작한다.
- G 중간 체크포인트는 사용하지 않는다.
- F에서 G로 넘어간 후 G에서 사망하면 F를 다시 플레이하지 않는다.
- F는 구역 진입 시 배치된 적 전체를 활성화한다.
- G는 전반부와 후반부 두 그룹으로 분리하여 순차 활성화한다.
- 활성화된 적은 플레이어를 인식하고 플레이어 방향으로 이동한다.
- G 첫 그룹 전멸 후 내부 통로를 개방하고,
  플레이어가 후반부 진입 트리거에 도달하면 두 번째 그룹을 활성화한다.
- 사망 재시작 시 체력을 완전히 회복한다.
- 이미 본 전투 도입 대화는 재생하지 않고 전투 상태만 초기화한다.
- 구역에 이미 배치된 얇은 도형을 임시 전투문으로 사용한다.
- 적이 남아 있으면 얇은 문 도형과 충돌을 활성화하고 전멸 시 비활성화한다.

### 권장 구현 구조

- 배치 적은 구역 진입 전 비활성 또는 대기 상태로 둔다.
- 플레이어가 전투 시작 트리거를 통과하면 적과 출구 잠금을 활성화한다.
- 배치 적 전체의 생존 상태를 추적해 0명이 되면 출구를 해제한다.
- 사망 재시작 시 현재 구역의 모든 적과 위험물 상태를 초기화한다.
- 적 종류가 정해지기 전까지 `EnemySlot_F_01`, `EnemySlot_G_01` 같은 빈 슬롯으로 준비한다.

### F 구역 구현 결과

- F에 배치된 적 3기를 구역 진입 시 동시에 활성화한다.
- 활성화된 임시 적은 최종 FSM이 연결되기 전까지 플레이어의 X 방향을 추적한다.
- 팀원이 배치한 가장 오른쪽의 얇은 흰 도형을 출구 잠금문으로 사용한다.
- 적이 한 기라도 살아 있으면 문 충돌을 유지하고, 세 기를 모두 처치하면 문을 연다.
- 플레이어가 전투 중 사망하면 F 시작점에서 체력을 회복한 상태로 다시 시작한다.
- 재시작 시 적 3기와 출구 잠금 상태도 함께 초기화한다.
- 기존 순차 전투·웨이브 구현은 F에서 비활성화했으며, F는 동시 활성화 규칙만 사용한다.

### G 구역 구현 결과

- F의 적을 모두 처치하면 `QST-TUTO-007-B`가 시작되고 F 출구를 통해 G 시작점으로 이동한다.
- G 진입 시 전반부 적 2기만 동시에 활성화하며, 후반부 적 2기는 비활성 상태로 대기한다.
- 전반부 적을 모두 처치하기 전에는 내부 차단문과 최종 출구문을 모두 잠근다.
- 전반부 적 전멸 시 팀원이 배치한 얇은 흰 도형 `Square (60)`을 내부문으로 열어 통로를 개방한다.
- 플레이어가 열린 통로 뒤의 `G01_후반부진입_TRIGGER`를 통과해야 후반부 적 2기가 활성화된다.
- 후반부 적을 모두 처치하면 `Square (63)`에 연결된 최종 출구문을 열고 `QST-TUTO-008`로 진행한다.
- 방향 화살표는 전반부 동안 내부 통로를 가리키고, 후반부 진입 후 최종 출구로 목표를 변경한다.
- G에서 사망하면 G 시작점으로 돌아가며 전반부·후반부 적, 두 문의 잠금 상태를 처음부터 초기화한다.
- G 완료 후 페이드 전환으로 선착장 시작점에 도착하며, F 전투는 다시 실행하지 않는다.
- G 환경 위험물 동작 연결을 완료했으며 다음 연동 대상은 선착장·헬테 조우 흐름이다.

## 10. 환경 위험물

### 확정

- 빨간 도형: 화염 방출 위험물.
- 파란 도형: 바람 방출 지형.
- 갈색 도형: 용암.
- 화염과 용암에 닿으면 플레이어 체력이 감소한다.

### 확정 동작

- 화염은 예고 → 분출 → 휴식 주기를 반복한다.
- 분출 중 접촉하면 최대 체력 10% 피해, 짧은 넉백과 피격 무적을 적용한다.
- 바람은 상승력을 제공하지만 활공 버튼을 대신 입력하지 않는다.
- 플레이어가 Space를 계속 누르고 있을 때만 활공 상태가 된다.
- 바람은 플레이어를 위로 밀어주되 Space 입력 없이 활공 상태로 전환하지 않는다.
- 용암에 빠지면 최근 안전 지점으로 즉시 복귀시키고 최대 체력 20% 피해를 준다.
- 환경 피해로 체력이 0이 되면 일반 사망과 동일하게 현재 구역 시작점으로 돌아간다.
- 수치는 인스펙터에서 조정 가능하게 노출한다.

### G 구역 구현 결과

- G 원본 도형의 실제 색상값을 분석해 빨간 도형 2개, 파란 도형 2개, 갈색 도형 1개를 자동 연결했다.
- 빨간 도형은 점멸하는 `예고 0.65초 → 연속 표시 분출 1초 → 숨김 휴식 1.2초`를 반복한다.
- 분출 중 접촉하면 기존 전투 시스템을 통해 최대 체력 10% 피해와 수평·상향 넉백을 적용한다.
- 피격 무적과 체력 HUD, 체력이 0이 되었을 때의 사망 처리는 기존 전투·재시작 흐름을 그대로 사용한다.
- 파란 도형의 상승기류는 플레이어가 범위 안에서 `Space`를 유지할 때만 상승력을 적용한다.
- 상승기류 자체는 활공 입력을 켜지 않으므로 버튼을 놓으면 즉시 상승 보정이 중단된다.
- 갈색 도형 `Square (37)`은 최대 체력 20% 피해를 주는 용암으로 연결했다.
- 용암 앞에 안전지점 트리거를 배치했으며, 생존 시 최근 안전지점으로 즉시 복귀한다.
- 용암 피해로 사망하면 안전지점 순간이동을 생략하고 G 구역 시작점 재시작 흐름으로 넘긴다.
- G 재시작 시 최근 안전지점은 G 시작점으로 초기화되고 화염 주기도 예고 단계부터 다시 시작한다.

## 11. H 구역: 헬테 선착장

### 확정

- 헬테는 선착장 아래쪽 전투 공간에 배치한다.
- 현재 선착장 도형은 미완성이다.
- 헬테 전투 시작 시 화면 하단에 보스 체력바를 표시한다.
- 헬테 패턴은 이도류, 블링크, 고속 대시, 2페이즈 칼 소환 기획을 따른다.
- 보스전 재도전 시 이미 본 조우 대화는 생략하고 전투 시작 직전 상태에서 재시작한다.
- 재도전 시 체력을 완전히 회복하고 헬테 상태와 전투 위험물을 초기화한다.
- 헬테는 판도라 습격 소식을 듣고 직접 프로메를 막으러 등장한다.
- 데미우르고스로서의 책무와 나디르에 대한 애정 사이의 갈등을 조우 대화에 반영한다.

### 미결정

- 상단 ㄷ자 도형의 최종 용도.
- 보스전 출입구 잠금의 시각 표현.
- 선착장 추가 블록아웃을 Codex가 만들지 팀원이 완성할지.

### H 구역 구현 결과

- 팀원 원본 선착장을 분석해 하단 폭 60 일자 바닥을 접근로와 보스 아레나로 사용한다.
- G 완료 시 페이드 전환으로 하단 왼쪽 시작점에 도착하고 `H_Helte_Integration`만 함께 활성화한다.
- 진입 직후에는 확정 대사 중 테우스·프로메 2줄을 먼저 보여 주며, 대화 중 이동 입력은 차단한다.
- 약 30유닛의 접근 구간을 지난 뒤 헬테가 보이는 지점에서 헬테·프로메 조우 2줄을 별도 재생한다.
- 조우 대화 지점과 보스 시작 트리거를 분리해 대화 도중 전투가 시작되지 않게 했다.
- 조우 대화를 본 뒤에는 런타임 체크포인트를 전투 직전으로 갱신한다. 이후 사망 재도전에서는 대화를 반복하지 않는다.
- 기존 헬테 이도류·블링크·대시·2페이즈 칼 소환 FSM, 보스 체력바, 입구 잠금, 사망 초기화를 선착장 좌표로 이식한다.
- 기존 광물 저장고 블록아웃은 비활성화하고, 팀원 선착장 자식 트랜스폼은 이동시키지 않는다.
- 하단 원본 바닥에 충돌이 없을 때만 `BoxCollider2D`를 보완하며, 보스 아레나 안전용 기술 바닥의 렌더러는 숨긴다.

### H 구역 폴리싱 결과

- 헬테 소개 카드는 선착장 진입 시점이 아니라 실제 헬테 조우 2줄이 끝난 뒤 표시한다.
- 소개 카드 설명은 폐기된 펄스 표현을 제거하고 이도류·블링크·고속 대시 대응으로 정리했다.
- 조우 대화가 시작되면 목표 화살표의 다음 목적지를 뒤쪽 대화 트리거가 아닌 아레나 입구로 전환한다.
- 보스 시작 트리거는 대화 또는 소개 카드가 입력을 점유하는 동안 작동하지 않는다.
- 보스 경고 시간을 `1.1초`로 늘리고, 경고가 시작되는 순간부터 카메라가 프로메와 헬테를 함께 프레이밍한다.
- 보스 체력바와 보스 HUD 모드는 실제 공격 패턴 활성화보다 먼저, 경고 연출 시작과 함께 표시한다.
- 경고 종료 후에만 헬테 본체 충돌과 FSM 공격 패턴을 활성화한다.

### 플레이어 대시 규칙

- 대시 지속 시간은 `0.16초`이며 그동안 플레이어 전투 Actor에만 대시 무적을 적용한다.
- 재사용 대기시간 `0.5초`는 대시가 끝난 시점부터 계산한다. 따라서 대시 시작부터 다음 사용까지는 총 `0.66초`다.
- 대화·페이드·재시작으로 대시가 강제 중단되면 대시 무적도 즉시 해제한다.
- 피격 후 무적과 대시 무적은 별도 타이머로 관리해 어느 한쪽이 끝나도 다른 무적을 잘못 해제하지 않는다.

## 12. 확정된 후반부 서사와 엔딩

- `TUTO_A_03`에서 에온·아르온과 직접 재회하고 대피 전 작별 대화를 진행한다.
- 헬테 전투 종료 후 패스키와 도면을 전달받는 대화를 최신 노션대로 적용한다.
- 멀리 남아 있는 판도라 부대의 불빛으로 습격이 완전히 끝나지 않았음을 보여준다.
- 프로메가 제니스를 바라보는 동안 제니스가 화면상 점점 가까워지게 연출한다.
- 제니스 접근은 실제 오브젝트 이동 또는 카메라 줌을 바로 고정하지 않고,
  블록아웃 단계에서는 제니스 대체 도형이 점차 커지는 방식으로 검증한다.
- 프로메의 다음 목적지가 제니스임을 암시한 뒤 페이드 아웃하고 DEMO를 종료한다.

## 13. 기존 시스템 이식 범위

다음 시스템은 신규 씬에 새로 재작성하지 않고 기존 `TutorialScene`에서 이식·재연결한다.

- `StageSystems`
- 실제 `PlayerRoot`
- 카메라 추적 및 구역별 카메라 프로필
- `TutorialHUD`
- 대화, 설명창, 자막, 목표 화살표
- 페이드 구역 전환
- 훈련 진행 및 행동 범위 판정
- 낙하물·투사체 훈련
- 부츠·모듈 지급 및 장착
- 체크포인트와 사망 재시작
- F/G 적 전멸 게이트
- 헬테 보스 FSM 및 체력바
- 튜토리얼 완료·결과 화면

## 14. 구현 단계

### 1단계: 의사결정 고정

- 이 문서의 모든 `미결정` 항목을 사용자와 확정한다.
- 최신 노션의 `[제안]` 중 채택 여부를 기록한다.

### 2단계: 안전한 통합 계층 생성

- 신규 씬에 `GameplayIntegrationRoot`를 생성한다.
- 팀원 레벨 도형 자식이 변경되지 않았는지 전후 검증한다.
- 실제 Player, 카메라, HUD, StageSystems를 연결한다.

### 3단계: A/B/C/D 본부 내부 흐름

- 회의장·숨겨진방 재방문 상태를 연결한다.
- C 복도를 제작 또는 수령해 3회 방문 상태를 구현한다.
- 수정 훈련장에 단계별 활성화, 실패 재시작, 습격 연출을 연결한다.

### 4단계: E 외부와 긴박한 이동

- 외부 블록아웃을 제작 또는 수령한다.
- 습격 목격, 이동 자막, F 진입 전환을 연결한다.

### 5단계: F/G 전투 구역

- 적 슬롯과 직접 배치 적을 연결한다.
- 전멸 게이트, 사망 시 구역 처음 재시작, 위험물을 구현한다.

### 6단계: H 헬테 보스전

- 선착장 하단에 헬테를 배치한다.
- 입장 잠금, 보스 FSM, 체력바, 사망 재시작, 종료 대화를 연결한다.

### 7단계: 대화·자막·UI 폴리싱

- 필수 대화가 이동 때문에 묻히지 않는지 검사한다.
- Space 진행, HUD 겹침, 화면 비율, 카메라 크기를 점검한다.
- 모든 방향 유도와 잘못된 방향 반응을 검증한다.

### 8단계: 검증

- 프로젝트 전용 튜토리얼 씬 검증기를 통과한다.
- EditMode 테스트를 통과한다.
- 실제 씬 PlayMode 스모크 테스트를 신규 구조에 맞게 갱신하고 통과한다.
- 시작부터 헬테 종료까지 1회 완주 및 각 구역 사망 재시작을 수동 검증한다.

## 15. 완료 기준

- 최신 확정 시나리오 순서가 누락 없이 실행된다.
- 모든 필수 대화와 자막이 플레이어 이동 속도와 무관하게 노출된다.
- C와 회의장은 방문 횟수에 맞는 상태를 보여준다.
- 각 훈련은 지정된 구역 안에서 수행한 행동만 인정한다.
- F/G는 모든 적 처치 전 진행할 수 없다.
- F/G 사망 시 해당 구역 시작 상태가 완전히 복구된다.
- 화염·바람·용암이 확정 규칙대로 작동한다.
- 헬테 보스전과 결과 흐름까지 1회 플레이가 가능하다.
- 팀원이 만든 레벨 도형 자식 트랜스폼은 변경되지 않는다.
