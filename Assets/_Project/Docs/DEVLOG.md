# Prometheus 개발일지

프로젝트의 주요 기능 변경, 검증 결과와 협업 기준을 날짜순으로 기록한다. 세부 사용법은 각 항목에 연결된 문서를 따른다.

## 2026-08-12 — Player 빌드 훈련·F/G 런타임 복구

- `EditorOnly` 저작 마커가 Player 빌드에서 제거되면서 점프 투사체와 근접 허수아비 관리자가 비활성화되던 근본 원인을 수정했다.
- 점프 발사·도착·재시작 앵커와 근접 허수아비 위치는 빌드에 남는 단계 내부 런타임 오브젝트에서 자동 복구한다.
- 구간 스킵은 퀘스트를 먼저 전환한 뒤 목적 구역과 적 관리자를 켜며, F/G 적 관리자는 `OnEnable` 때 현재 퀘스트를 재동기화한다.
- 실제 macOS Player QA 결과: 점프 투사체 표시, 근접 허수아비 표시, F 적 3기·배경 F, G 적 2기·배경 G 모두 확인 및 `PASS`.
- 마커는 저작 기준으로 유지하되 런타임 기능의 유일한 필수 참조로 사용하지 않는 규칙을 확립했다.

## 2026-08-12 — 빌드 훈련 흐름·QA 스킵 복구

- 릴리스 빌드에서 차단되던 퀘스트 강제 전환을 데모 QA용 F8/F9 경로에 허용해 위치와 HUD 진행도가 분리되지 않게 했다.
- `F8`은 F→G→헬테 순차 구간 이동, `F9`는 헬테 직전 직행으로 역할을 분리했다.
- 점프 훈련 전방 투사체를 Unlit·상위 정렬 순서로 강제해 빌드 조명과 플랫폼에 가려지지 않게 했다.
- 훈련 단계 Coroutine이 중단되거나 예외가 발생해도 페이드 오버레이와 입력 잠금이 반드시 해제되도록 정리했다.

## 2026-08-12 — DEMO_V1 저장·타이틀·더블점프 교체 패치

- 타이틀은 `narthex_save.json`, 튜토리얼 씬은 `narthex_tutorial_save.json`을 사용하던 이중 저장 경로를 단일 정식 저장소로 통합했다. 초기화와 새 게임은 레거시 저장까지 제거해 회의장 위치에서 HUD만 4단계로 복원되는 혼합 상태를 방지한다.
- 빌드에서 `EditorOnly` 최고점 마커가 제거되어도 동일 위치에 런타임 Trigger와 유도 화살표 목표를 복구하는 안전장치를 추가했다.
- 설정 패널을 현재 Canvas 크기에 맞춰 자동 축소·중앙 정렬해 타이틀과 일시정지 UI가 창 밖으로 벗어나지 않게 했다.
- 저장 데이터에 현재 튜토리얼 퀘스트와 프로메의 마지막 X/Y 좌표를 추가했다.
- `저장 및 나가기 → 이어하기`가 같은 퀘스트와 좌표를 복원하며, `새 게임 시작`은 설정만 유지하고 진행을 초기화한다.
- 타이틀의 실제 `보스전` 버튼 클릭이 `BossDevelopmentScene`으로 이동하는 테스트를 추가하고 Build Settings의 5개 씬 활성화를 재확인했다.
- AI Scene Toolkit으로 원인을 확인했으며, 팀원이 배치한 씬은 변경하지 않고 런타임 보강으로 해결했다. Doctor는 기존 비가시 충돌체 경고 54건이며 신규 오류는 없다.
- Unity 전체 테스트: EditMode `120/120`, PlayMode `15/15` 통과, Console 컴파일 오류 `0`.
- Windows·macOS 릴리스 빌드에서도 `F8`(F 구역)과 `F9`(F→G→헬테 순차 이동) 구간 스킵을 유지했다.
- 타이틀 설정 하단에 즉시 실행형 `초기화` 스프라이트 버튼을 추가해 저장·이어하기·로컬 설정·캐시를 시연 전 상태로 한 번에 정리할 수 있게 했다.
- 초기 튜토리얼의 훈련장 출구는 퀘스트 ID와 별개로 `숨겨진 방 복귀 완료 + 패스키 보유`를 한 번 더 검증해, 오른쪽으로 이동해 필수 루트를 건너뛰지 못하게 했다.
- 점프 훈련 투사체는 단계 루트가 활성화되는 순간 현재 퀘스트를 다시 확인해, 이벤트 구독 순서와 무관하게 오른쪽 벽에서 스프라이트가 발사되도록 보강했다.
- 튜토리얼 일시정지 음량 슬라이더의 채움 막대가 앵커 너비에 고정 너비를 중복 가산하던 문제를 제거해, 0~100% 전 구간에서 패널 안에 유지된다.
