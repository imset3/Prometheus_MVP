## 2026-08-04 — 튜토리얼 표시 보정 및 헬테 밸런스 1차 적용

### 튜토리얼

- 생성된 테우스 PNG를 일반 동행 상태의 런타임 아트 슬롯으로 연결했다.
  - 기본 스케일을 `0.3`으로 낮춰 플레이어와 겹치던 큰 크기를 줄였다.
  - 숨겨진 방에서는 캐릭터 스프라이트를 표시하지 않고, 테우스가 기존 빛 코어·빔 연출 자체로 유지되도록 고정했다.
- 대화창 프로필이 화자별 실제 스프라이트를 자동 선택하도록 했다.
  - 프로메, 테우스, 에온·아르온·엘륨, 크리온 슬롯을 `Resources/TutorialArt`에서 읽는다.
  - 음원이 없는 것처럼 프로필 아트가 없는 화자는 기존 색상 플레이스홀더로 안전하게 폴백한다.
- 근접 훈련의 `Enemy`, 원거리 훈련의 `RangedTarget_01~03`가 단계 활성화 시 다시 보이도록 보정했다. 표적 스프라이트는 다른 도형 뒤에 묻히지 않도록 최소 sorting order를 적용한다.
- 더블점프 단계에 진입하면 `Low → Landing → High` 마커 이름을 기준으로 발판을 낮은 곳 → 중간 → 최고 지점으로 정렬한다. 최고 지점은 기존 `DoubleJumpPlatform_High_ART_SLOT` 및 장비 목표 마커가 사용한다.

### 헬테 보스 개발씬

- `TutorialBossArenaHost`가 전투 시작 시 헬테 체력을 `2500`, 프로메 체력을 `500`으로 적용한다. 훈련장/일반 구간의 프로메 체력은 `100`을 유지한다.
- 프로메 사망 시 전투당 한 번 테우스 구조가 발생한다. 체력을 전부 회복하고 `1.25초` 무적을 거친 뒤 재개하며, 그 다음 사망부터는 기존 체크포인트 재시작을 사용한다.
- 헬테가 2페이즈로 넘어갈 때 프로메 체력을 한 번 전부 회복한다.
- 패턴 사이 회복 시간을 줄이되 기본·블링크·돌진·X베기 예고 시간은 최소값을 보장해 경고가 사라지지 않게 했다.
- 헬테 시각 슬롯의 Y 오프셋을 전투 바닥 기준으로 맞춰 공중에 떠 보이는 기본 도형을 내렸다.
- 테우스가 전투 중 자동 기본 공격과 별도 쿨타임 자동 스킬을 사용할 수 있는 선택형 `TheusCombatSupportHost`를 추가했다. 현재 기본값은 공격 `3.2초/10`, 스킬 `7초/45`이며 VFX·사운드는 후속 아트 연결에서 교체한다.

- 현재 헬테 전투용 부트스트랩과 우호 패턴은 그대로 유지하되, 이후 다른 보스도 같은 격리 개발 흐름을 사용할 수 있는 이름으로 정리했다.
- 실제 이동 테스트에서 조우 대화 후 좁은 아레나 트리거를 지나치면 전투가 시작되지 않는 문제를 재현했다.
- 보스 아레나 진입에도 연속 이동 경로 스윕 판정을 적용하고, 빠르게 트리거를 통과하는 PlayMode 회귀 검증을 추가했다.
- 실제 입력으로 조우 대화 2줄, 체력바 `5000/5000`, 기본 콤보·블링크·페이크 블링크, 자비 후퇴, 근접 피격과 사망 후 재시작을 확인했다.
- Unity 전체 테스트: EditMode `50/50`, PlayMode `7/7` 통과, Console 오류 `0`.
- 밀착 공격 위주 플레이에서 2페이즈 전에 사망하기 쉬운 문제를 확인했고, 아래 UX 밸런스 패스에서 보정했다.

## 2026-07-31 — 헬테전 생존·가독성 UX 보정

- 자비 행동을 전투당 1회에서 재충전형으로 변경했다.
- 보스 개발씬 기준 자비 재충전은 `20초`, 회복은 최대 체력의 `60%`, 후퇴 후 대기시간은 `1.8초`다.
- 자비 행동이 사용 가능한 동안에는 같은 연계의 후속타로 체력 25% 아래까지 즉시 밀리지 않게 유지한다.
- 기본 공격 예고를 `0.28초 → 0.38초`, 페이크 블링크의 무공격 빈틈을 `0.9초 → 1.15초`로 늘렸다.
- 보스 체력 `5000`, 공격 피해와 페이즈 기준은 유지해 5분 목표를 훼손하지 않고 학습 여유만 늘렸다.
- 실제 플레이에서 첫 번째와 두 번째 `MercyRetreat` 재발동, 60% 회복, 사망 후 정상 재시작을 확인했다.
- Unity 전체 테스트: EditMode `50/50`, PlayMode `7/7` 통과, Console 오류 `0`.
- Scene Doctor의 기존 비가시 충돌체 경고 `54건`은 레벨 충돌체에 대한 기존 경고이며 이번 변경으로 증감하지 않았다.

## 2026-07-31 — 헬테 우호적 패턴 프로토타입

- `BossDevelopmentScene.unity`에서만 페이크 블링크, 카운터 자세와 자비 행동을 활성화했다.
- 기존 기본 공격·블링크 X 베기·칼 소환은 교체하지 않고 신규 패턴 사이에 유지한다.
- 카운터 자세를 공격하면 피해 없이 밀려나며, 기다리면 1.2초의 근접 반격 기회가 열린다.

- 자비 행동이 사용 가능한 동안 같은 연계의 후속타로 사망하지 않도록 체력 25%를 보장하고 60%까지 복구한다.
- 최종 시험은 기존 패턴과 신규 패턴을 섞은 6박 순환으로 확장했다.
- 튜토리얼 씬은 검증 전까지 기존 패턴 설정을 유지한다.

## 2026-07-30 — 헬테 FSM 1차 폴리싱

### 개선

- 재도전 시 패턴 플래너, 2페이즈 연출 상태와 헬테 최초 위치를 초기화했다.
- 헬테 최대 체력을 `100 → 240 → 6000`으로 조정하고 2페이즈 진입점을 `55%`로 설정해 5분 전투의 1차 기준을 마련했다.
- 단순 체력 소모를 줄이기 위해 최대 체력을 `6000 → 5000`으로 낮추고, `55%` 2페이즈와 `20%` 최종 러시로 전투 리듬을 세분화했다.
- 2페이즈부터 회복·이동 시간을 단계적으로 줄이고 투사체 속도와 피해량을 올리되, 공격 예고 시간은 유지했다.
- 최종 러시는 `블링크 → 기본 → 칼 소환 → 기본` 순환으로 구성해 읽을 수 있는 클라이맥스를 만든다.
- `HelteCombatTelemetryHost`가 전투 시간과 기본 콤보·블링크·칼 소환 횟수를 측정한다.
- 헬테 개발 씬에만 계측 오버레이를 표시하고, 처치 시 목표 `300초`와의 차이를 Console에 기록한다.
- `HeltePatternVfxHost`를 추가해 FSM 상태별 VFX 오브젝트를 Inspector에서 연결할 수 있게 했다.
- 하나의 상태에 ParticleSystem, 트레일, 검광 등 여러 VFX 슬롯을 겹쳐 연결할 수 있다.
- 블링크 돌진을 `경로 예고 → 무피해 이동 → X 베기 예고 → 판정` 상태로 분리했다.
- 돌진 경로 예고 시간을 `0.3초`로 추가했다.
- 전투 도중 플레이어나 보스가 사망하면 남은 이동·공격 연출이 이어지지 않게 했다.
- 헬테 전용 개발 씬의 HUD가 구간 스킵 이후 이전 튜토리얼 목표에 남는 문제를 수정했다.
